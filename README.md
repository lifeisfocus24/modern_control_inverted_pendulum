# Modern Control of a Linearized Inverted Pendulum

## Overview
This project implements a modern control approach for a linearized inverted pendulum on a cart system using state-space methods. The goal is to stabilize the pendulum about its upright equilibrium using state feedback and state estimation.

The project will include:
- linearized state-space modeling
- LQR state feedback control
- observer design for state estimation
- simulation under disturbance and sensor noise
- response visualization and performance analysis

## Project Goals
- Derive and implement the linearized state-space model
- Design an LQR controller
- Design a state observer
- Evaluate closed-loop performance
- Prepare the project for later ROS2 integration

## Planned Files
- `pendulum_ss.py`: system model and matrices
- `lqr_observer.py`: controller and observer design
- `sim_and_plot.py`: simulation and plotting
